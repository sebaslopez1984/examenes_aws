==========================================================
 COMO CORRER EL SIMULADOR DE EXAMENES AWS
==========================================================

ENLACES RAPIDOS:
- Local (general):             http://localhost:8000/Examenes.html
- Directo Architect Associate: http://localhost:8000/Examenes.html?cert=architect_associate
- Directo Cloud Practitioner:  http://localhost:8000/Examenes.html?cert=cloud_practitioner
- Online (GitHub Pages):       https://sebaslopez1984.github.io/examenes_aws/

----------------------------------------------------------
 OPCION 1: WINDOWS (PowerShell o CMD)
----------------------------------------------------------
1. Entrar a la carpeta del proyecto:
   cd c:\examenes_aws

2. Levantar el servidor local:
   - Con Node.js (instalado en esta PC, cero dependencias):
     node server.js

   - O si tenes Python instalado:
     py -m http.server 8000
     (o: python -m http.server 8000)

3. Abrir en el navegador:
   http://localhost:8000/Examenes.html

----------------------------------------------------------
 OPCION 2: MAC (Terminal)
----------------------------------------------------------
1. Entrar a la carpeta del proyecto y ejecutar:
   python3 -m http.server 8000
   (o tambien: node server.js)

2. Abrir en el navegador:
   http://localhost:8000/Examenes.html

----------------------------------------------------------
 OPCION 3: VS CODE / ANTIGRAVITY (Live Server)
----------------------------------------------------------
1. Abrir la carpeta examenes_aws.
2. Click derecho sobre Examenes.html -> "Open with Live Server".

----------------------------------------------------------
 ESTRUCTURA DE CARPETAS:
----------------------------------------------------------
- examenes/cloud_practitioner/    -> JSONs de Cloud Practitioner (CLF-C02)
- examenes/architect_associate/   -> JSONs de Solutions Architect Associate (SAA-C03)
- estudio/cloud_practitioner/     -> Chuleta, evaluaciones y contexto de CLF-C02
- estudio/architect_associate/    -> Chuleta, evaluaciones y contexto de SAA-C03

----------------------------------------------------------
 ACTIVAR / DESACTIVAR BOTON DE PISTA ("Mostrar Pista 💡"):
----------------------------------------------------------
- Archivo: c:\examenes_aws\app.js (arriba de todo, línea 4)
- Variable:
    const ayuda_activa = false;
- Para ver el botón "Mostrar Pista 💡" (en Modo Padawan): cambialo a `true` y recargá la página.
- Para ocultarlo y no tentarte: dejalo en `false`.

IMPORTANTE:
- No abras Examenes.html con doble click directo (file://), porque el navegador bloquea la carga de los .json; usá siempre localhost o GitHub Pages.
